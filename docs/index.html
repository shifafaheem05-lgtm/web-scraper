Run it yourself

Python 3.9 or newer. The scraper obeys robots.txt and waits between requests.

1. Install

git clone https://github.com/shifafaheem05-lgtm/web-scraper.git cd web-scraper pip install -e ".[excel]"

2. Scrape with details and write a report like this one

webscraper scrape --max-pages 2 --details -o output/books.csv -o output/report.html

3. Track price changes between runs

webscraper scrape --all-pages --db output/history.db webscraper history --db output/history.db "attic"
